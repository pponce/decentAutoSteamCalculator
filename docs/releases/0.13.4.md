Install Auto Steam Calculator directly through **Decaid → Plugins → + → GitHub Release**.

- Repository: `pponce/decentAutoSteamCalculator`
- Asset name: leave blank.

Then open **Streamline → Settings → Extensions → Auto Steam Calculator**.

### Changes

- Adds a packaged GitHub Release for stable installations and future updates.
- The calculator's Update and Approve & Update controls now support both GitHub Release and GitHub Branch installations.
- Release installations check the published release, so unpublished changes on `main` are not offered as release updates.
- Join beta works from either stable install method. Return to stable installs the latest published stable release once its version is equal to or newer than the installed beta.
- Existing `main` and `beta` branch installations continue to work. Updates and channel changes retain saved settings and calibration readings.

Requires Decaid v0.8.6 or newer and official Streamline.js v0.1.114 or newer.
