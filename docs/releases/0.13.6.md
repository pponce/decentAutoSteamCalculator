# Auto Steam Calculator 0.13.6

With Streamline v0.2.13 or newer, the extension page hides the duplicate
calculator fields and keeps the enable, version/update and Open controls.
Configure pitchers and calibrations inside Open. All settings declarations
remain present, preserving existing settings and calibration measurements.

Streamline v0.2.13 now supplies its complete settings address to Open. The
calculator's existing return handler uses that address for both ← Settings and
a successful Save settings, preserving the actual skin port and route. A direct
visit falls back to Decaid's browser settings dashboard.

Older Streamline versions, other skins and Decaid's native Plugins screen may
continue displaying individual fields. This change needs no Decaid upgrade on
0.8.8. Calculator identity, permissions and API v5 remain unchanged.
