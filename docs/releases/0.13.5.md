The calculator's existing update controls now follow your selected channel:

- **Beta:** After opting in through Join beta, Update beta installs newer versions from the `beta` branch. Promoted stable builds on that branch remain available without leaving beta.

- Updates that request additional permissions retain the approval step. Unpublished main-branch pending updates are not offered as stable updates.

Updating stable through this UI changes an existing main-branch installation to release tracking, preserving settings and calibration readings. Opening the page alone does not reinstall the plugin.
